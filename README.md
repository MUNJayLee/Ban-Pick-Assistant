# 王者 BP 助手

基于 Tauri 的王者荣耀 BP 分析桌面工具，集成天元之弈梯度数据，提供智能英雄推荐和阵容分析。

## 功能特性

- **智能 BP 推荐**：根据阵容克制关系、梯度评分实时推荐最优英雄
- **梯度数据同步**：对接天元之弈 API，每日自动更新英雄梯度榜
- **位置分路显示**：英雄按对抗路/中路/发育路/打野/游走分类展示
- **BP 记录与统计**：记录每局 BP 结果，自动判断预测正确率
- **个人战绩追踪**：标记自己使用的英雄，统计个人胜率
- **数据仪表盘**：梯度排名、登场率、禁用率一目了然

## 技术栈

- **前端**：React 18 + TypeScript + Tailwind CSS + Vite
- **桌面端**：Tauri v2（Rust）
- **数据源**：天元之弈 (tianyuanzhiyi.com)
- **包管理**：npm

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 生产构建
npm run build

# 构建桌面安装包
npm run tauri build
```
