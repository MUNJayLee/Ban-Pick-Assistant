## 三、文档维护约定

1. **命名**：类型 + 日期，如 `TEST_REPORT_YYYY-MM-DD.md`；长期文档用大写主题名（`ARCHITECTURE.md` / `USER_GUIDE.md`）。
2. **登记**：新增文档必须在本索引对应分类登记，并标注状态（🟢 / 🟡 / ⚪）。
3. **过期处理**：任务完成后把文档状态改为 ⚪ 历史归档，**不删除**；结论若有长期价值，先并入 `ARCHITECTURE.md` / `USER_GUIDE.md`。
4. **时效性文档**：进度/复盘类默认 🟡 或 ⚪，不作为当前状态依据；当前状态以 README、ARCHITECTURE 与代码为准。
5. **截图/产物**：测试截图、诊断帧等二进制产物放 `_diag/`，文档中只引用文件名，不复制进 `docs/`。
